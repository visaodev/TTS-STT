# TTS e STT
 Text To Speech (Texto para Fala) e Speech To Text (Fala para Texto)

 Demonstra o uso de TTS e STT através da API do navegador, usando apenas javascript com html e css (Tailwind).
 
 Documentação oficial
 https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API


Necessário habilitar o uso de microfone para usar o STT.
